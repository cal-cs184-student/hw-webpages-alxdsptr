Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

De Casteljau's algorithm is to apply linear interpolation using parameter t to each pair of ajacent control points to get a new set of control points, and repeat this process until we only have one control point left, which is the point on the curve corresponding to the parameter t. Then iterate t from 0 to 1 to get the whole curve.

To implement this, I only need to implement the evaluateStep function, and other procedures are done by the provided code. To implement evaluateStep, I just simply iterate i from 0 to n-2, and compute the linear interpolation of control_points[i] and control_points[i+1] using parameter t, and push it into the result vector.

Part 2: Bezier surfaces with separable 1D de Casteljau

De Casteljau's algorithm extends to Bezier surfaces by applying the 1D algorithm to each row of control points using parameter u to get a new set of control points, and then applying the 1D algorithm to this new set of control points using parameter v to get the point on the surface corresponding to parameters u and v. Then iterate u and v from 0 to 1 to get the whole surface.

To implement this, I first implement evaluateStep function similar to the one in Part 1, and then implement evaluate1D function to apply evaluateStep size()-1 times to get the final point on the curve. Then I implement the evaluate function to first apply evaluate1D to each row of control points to get a new set of control points, and then apply evaluate1D to this new set of control points to get the final point on the surface. Part 6: Loop subdivision for mesh upsampling

I just simply followed the recommended procedures. First, iterate through all the vertices, compute their new positions according to the formula and store them in the new_position field. Then iterate through all the edges, compute the position of the new vertex and store it in the new_position field. Then we split all the edges, and flip the new edges that are connected to the old vertices. Finally, we update all the vertex positions to their new positions. Then iterate through all the existing edges and split them (and set the isNew variable correctly), also, set the new_position field of the new vertex to the new_position field of the edge. Then iterate through all the new edges, and flip those edges that connect one new vertex and one old vertex. Finally, update all the vertex positions to their new_position.

To avoid recursively splitting edges, when iterating all the edges and splitting them, I record the last edge in the list before the loop, and inside the loop, I check if the current iterator equals to that iterator pointing to the last edge, break the loop (since we always add the edge to the back of the list). Also, when flipping the new edges, to avoid unnecessary computation, I start from the next element of the recorded back iterator, instead of from the beginning of the list.

After loop subdivision, the volume of the mesh will shrink, and the sharp corners and edges will be smoothed out (they will move towards the center of the mesh and become more rounded). The images below clearly show these effects.

Pre-splitting: To reduce this effect, we can split the edges around the sharp corners to make the neighbors become closer to the sharp vertices, therefore they won't be pulled towards the center as much.

Asymmetric cube: As shown in the figure below, the original cube becomes asymmetric after subdivision. This is because some of the vertices have 5 neighbors, while others have 4 neighbors. And those vertices with 5 neighbors will be affected more by their neighbors, therefore will become more close to the center after subdivision, while those with 4 neighbors will be closer to their original positions. Therefore the cube will become asymmetric.

Preprocessing the cube: The solution is to split every diagonal edge on the surface of the cube, this will make every vertex of the cube to have 6 neighbors, and make the cube completely centrally symmetric, therefore it will remain symmetric after subdivision.
