Overview

For this project, we have been rewriting the original HW3 path tracer into a new general-purpose, GPU-oriented framework. Our primary goal has been rendering complex scenes much faster than the CPU-based implementation, ideally close to real-time.

Current Progress

  • Different model formats through Open Asset Import Library (assimp)
  • A modern display output pipeline (Vulkan) with interactive navigation
  • Path tracing via CUDA kernels with basic acceleration data structures (e.g., BVH) rewritten
  • Texture loading, including basic albedo textures, normal maps, and emissive textures
  • Cook-Torrance BRDF for most materials, Lambertian fallback for .dae files, and transmission for glass
  • Direct light sampling for emissive triangles using a global CDF built from triangle weights (proportional to area and average emissive luminance), enabling \(O(\log N)\) importance sampling
  • MIS using the power heuristic to combine NEE and BSDF sampling: \(w_{\text{light}} = p_{\text{light}}^2 / (p_{\text{light}}^2 + p_{\text{bsdf}}^2)\), \(w_{\text{bsdf}} = p_{\text{bsdf}}^2 / (p_{\text{bsdf}}^2 + p_{\text{light}}^2)\)
  • Denoising and upsampling for real-time: DLSS support and NVIDIA Real-Time Denoisers (NRD) (working with CUDA but not OptiX yet)
  • OptiX backend implementation, ported from CUDA path-tracing kernels to leverage RT-core hardware acceleration

Compared to our original plan, we are already far along in many aspects, and the framework can now render fairly large, complex scenes with both CUDA and OptiX acceleration.

Planned Next Steps

  • Light BVH for more efficient light importance sampling and reduced noise
  • Importance sampling for environment lighting
  • Volumetric rendering
  • ReSTIR support
  • Other noise-reduction attempts
